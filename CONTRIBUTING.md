# Contributing to rad-Authenticator

Thanks for your interest in the project. Community input is genuinely
valued, and there are a couple of great ways to help.

## Bug reports welcome

If something does not work as expected, please
[open an issue](https://github.com/radprogrammer/rad-authenticator/issues).
A useful report generally includes:

- What you did and what you expected to happen
- What actually happened (error messages, incorrect output, etc.)
- Your Delphi version and target platform
- A minimal snippet or steps that reproduce the problem

Reproducible reports, especially ones that fail against the RFC test
vectors, are the most helpful.

## Feature requests welcome

Ideas for new capabilities or improvements are encouraged. Please
[open an issue](https://github.com/radprogrammer/rad-authenticator/issues)
describing the use case and what you would like to see. Even if it is not
picked up right away, a well-described request is a useful record for the
future.

## Pull requests are not accepted

This is a personally maintained repository, and pull requests are not
accepted. Please do not open one -- it will be declined regardless of its
merits. This keeps authorship and licensing simple and lets development
stay focused.

If you have a change in mind, the best path is to open an issue describing
the problem or the idea. That way it can be considered and, if adopted,
implemented directly in the project.
